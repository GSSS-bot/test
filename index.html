建築事務による現場書類業務サポートの考え方

現場の仕事には、主に「現場業務」と「書類業務」があります。
「書類業務」を事務側で担うことで「現場業務」を進めやすくするために、建築事務チームを発足しました。

サポートが導入された背景

  • 現場の残業・事務負担の軽減
  • 若手が現場で学ぶ時間の確保
  • PC作業など、デスクに張り付いている事務のほうが効率的に行える業務を分担

現場判断が必要になる場面

書類業務の中には、事務だけでは前に進めないものがあります。
方針の決定や業者への最終的な対応など、現場判断が必要になる場合は判断・対応を現場へ戻します。

判断が必要になる具体例

例①：協力会社へ不備修正依頼を続けても解消しない

検査が近づき、事務からの催促にも反応がない場合、現場所長からの強い催促や
「その書類は不要」といった判断がないと平行線のまま無駄なやり取りが続いてしまいます。

例②：台帳検査前の準備・整備

書類を確認する中で「ここは検査で指摘されそうだ」と気づくケースがあります。
建築事務は検査に立ち会わないため、最終的な対応は現場判断となります。
事務からは事前準備の観点で助言を行いますが、採用するかどうかは現場で判断してください。

このマニュアルについて

このマニュアルは、各業務がどんな理由で必要なのか、
現場と事務でどのように役割分担するとスムーズなのか──その目安を共有するために作成しました。
現場と事務の両方が動きやすくなるよう、今後も相談しながら改善していければと考えています。

※ 本サイトは常に最新情報を保証するものではありません。
更新履歴・最終更新日を確認のうえ、判断に迷う場合や急ぎの案件は、建築事務まで直接確認してください。

早期契約にご協力ください

安全書類の提出依頼は契約完了（注文書送付）後のみ可能です。 早期契約は現場立ち上げの遅延や書類のやり直しを防ぎます。

現場で対応

  • 見積提出 → 契約手続きを早めに開始
  • 注文書送付（契約完了）を確認
  • 契約前入場が必要な場合は積算購買・建築事務へ事前相談

建築事務がサポート

・契約完了後のみGSで招待・提出依頼
・提出物のチェック／不備対応
・日程矛盾の有無を確認し、必要に応じて調整

未契約協力会社には依頼不可

未契約＝注文書未送付。
注文日 → 工期開始 → 入場日 の順が崩れると、 書類やり直し／注文書再作成／見積再発行の手戻りが発生します。

契約前依頼が可能なケース（例外）

  • 契約日程と入場日に矛盾がない
  • 入場の前倒し可能性がない
  • 協力会社がGS加入済（提出履歴あり）
  • 現場から直接依頼の声かけが可能

現場で対応

新規入場者アンケート提出

協力会社は入場前に作業員名簿の登録・提出が必要です。 現場と事務の役割分担を明確化し、例外対応・注意点も含めて記載します。

現場で対応

  • 新規入場者教育の実施
  • アンケートの誤記・読みにくい字の修正（必要に応じ代筆）
  • スキャンして提出（入場日ごと／協力会社混在OK／毎日推奨）

建築事務がサポート

  • 名簿登録状況の確認／不備の是正依頼
  • QR付アンケの運用支援、直行直帰などの特別対応

注意

QR付アンケの「送り出し教育」欄は元請側で登録する項目です。 出力時は「いいえ」表示で問題ありません。

手順（ロング版）

  1. 新規入場者教育を実施 → 相違があれば協力会社へ従業員情報の更新依頼
  2. アンケートをスキャンして提出（入場日ごと整理／混在OK）

特別対応（例）

直行直帰等でQR付アンケの出力・持参が困難な場合：

  • 前日までにメール／FAXで送付するなど柔軟対応（現場判断OK）

問い合わせ先（スキャン設定）

複合機の初期設定はJGS㈱が実施。 スキャン設定の不具合・変更がある場合はJGS㈱へ連絡し、併せて建築事務へ共有をお願いします。

安全書類（グリーンファイル）の提出依頼

協力会社へ安全書類（グリーンファイル）について、提出依頼・受領・初回チェックを行います。

現場で対応

  • 積算購買へ見積書を提出（契約開始）
  • 経理の注文書送付のタイミングで契約完了扱いということを認識
  • 協力会社との契約・書類提出状況は管理表「安全書類確認状況」で確認
  • 書類未提出の協力会社へ直接声かけ or 建築事務へ催促依頼

建築事務がサポート

  • 契約完了を確認し、GSで企業招待＋提出依頼メール送付、適宜電話連絡
  • 提出物の受領 → 初回チェック → 不備修正依頼
  • 書類提出・不備状況をExcel管理表へまとめ（現場へ共有可）
  • 書類提出状況を管理表「安全書類確認状況」に反映

注意

未契約（＝注文書未送付）の協力会社には依頼不可
日程矛盾・注文書再作成など大きな手戻りが生じるため　※詳細はこちら

全体の流れ

  1. 契約開始（現場所長）　　　：積算購買へ見積書を提出し、契約手続きを開始
  2. 協力会社追加（積算購買部）：管理表「安全書類確認状況」に協力会社追加
  3. 注文書送付（経理課）　　　：協力会社と現場所長へ注文書送付 → 契約完了
  4. 提出依頼（建築事務）　　　：GSで企業招待＋提出依頼 → 受領・初回チェック・不備修正依頼

提出期限・状況確認

  • 提出期限の目安：入場の1か月前まで
  • 最新の依頼・提出状況：管理表「安全書類確認状況」で確認

提出を急ぎたい場合（催促）

  • 現場から直接連絡（電話／Teams）
  • 建築事務へ共有 → 事務側からも催促・調整を実施

催促の例文（コピペ可）

「◯◯工事の安全書類につきまして、提出が未確認です。
入場は◯/◯予定のため、本日中のご対応をお願いいたします。」

よくある質問（FAQ）

Q. 契約前でも書類依頼したい場合？

A. 以下すべてを満たす場合、例外的に可能：

  • 入場日と契約日程に矛盾がない（注文日 → 工期開始 → 入場日の順が保たれる）
  • 入場日の前倒しの可能性がない
  • 協力会社がGS加入済（別現場で提出履歴あり）
  • 現場から直接の声かけが可能

補足（背景）

GS運用は契約と連動します。契約未整備のまま依頼すると、入力済み書類の作り直しや注文書の再発行が発生します。 そのため未契約協力会社への依頼は原則不可としています。

社会保険未加入者

作業員の社会保険加入は法令で義務付けられています。 未加入者は原則入場不可で、状況によっては行政指導の対象となります。 検査時の指摘を避けるための実務ポイントを整理します。

現場で対応

  • 入場予定者の加入状況を名簿で確認
  • 未加入の場合は所属協力会社へ是正依頼を促す
  • 掲示物・資料配布で加入推進を周知
  • 検査時は「是正中／指導中」である旨を説明

建築事務がサポート

  • 加入状況更新の依頼送付／名簿情報の確認・是正管理
  • 加入促進の資料提供（掲示・配布）

注意

法令上の義務のため、未加入作業員は入場不可です。

検査対応（背景）

名簿確認の際に未加入者が残っていると指摘の対象になります。 ただし次のような取り組みにより「指導中」として扱われ、指摘回避できた事例があります。

指摘回避の実例

  • 「本社にて対応・指導中」と説明し是正を示す
  • 国交省ガイドライン等の加入促進資料の掲示・配布を提示

Edge記憶のパスワード削除

Edge に保存された不要なログイン情報（ID/パスワード）を削除して、 誤ログインを防ぐための手順です。

① この業務の目的

不要な保存パスワードを削除し、誤アカウントでのログインを防ぐための操作です。

② 手順

  1. 右上メニュー →「設定」を開く
  2. 「パスワードとオートフィル」→「Microsoft パスワードマネージャー」
  3. 対象のIDを選択（例：グリーンサイト＝kensetsu-site.com）
  4. Windowsセキュリティ認証（PCログインパスワード）を入力
  5. 削除

【補足】よくある質問

  • 保存パスワードが多いほど誤ログインが起きやすくなります。
  • 共有PCでは、定期的な整理がおすすめです。
